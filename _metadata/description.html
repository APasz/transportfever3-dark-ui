Dark UI

An almost-black, monochrome interface theme for Transport Fever 3.

Features

  • Uses dark base colours and monochrome accents.
  • Preserves status colours, such as positive and negative values.
  • Offers optional game bar colour and contrast settings through UI Tweaks.
  • Requires no other mods for the base theme.

Compatibility

Mods using the game's shared palette inherit the theme. Custom skins, hard-coded colours, and colours baked into textures may remain unchanged. Other mods that replace the same palette may conflict.

Warnings, ownership colours, map overlays, and branding should stay distinct. Mod-specific styling is outside scope; compatibility patches belong in separate, opt-in mods.

Known limitations

Signal icons currently appear unaffected by interface themes.

Some custom or nested UI elements may remain unstyled or conflict with game bar customisation.
