Dark UI

An almost-black, monochrome interface theme for Transport Fever 3.

Features

  • Uses dark base colours and monochrome accents.
  • Preserves status colours, such as positive and negative values.
  • Requires no other mods.

Compatibility

Mods using the game's shared palette inherit the theme. Custom skins, hard-coded colours, and colours baked into textures remain unchanged. Other mods that replace the same palette may conflict.

Warnings, ownership colours, map overlays, and branding should stay distinct. Mod-specific styling is outside scope; compatibility patches belong in separate, opt-in mods.

Known limitation

Signal icons currently appear unaffected by interface themes.
